## Releasing

`riseno/k8s-mcp` and `riseno/homebrew-tap` are public from v0.1.0. To release: bump the
workspace version, date the CHANGELOG section, push `main`, then push a `vX.Y.Z` tag.
`release-gate.yml` runs the evals on kind 1.34 and 1.37 and only then dispatches
`release.yml`, which builds, attests, publishes the signed image and pushes the Homebrew
formula. Pre-release tags (`-rc.N`) build and attest but do not publish the image or formula
(`publish-prereleases = false`).

## Deviations
- ADR 0002: no separate `k8s-mcp-server` library crate (name clash with the published bin).
- ADR 0003: serde-saphyr and jiff.
- ADR 0004: list cache and empty provider crates deferred.
- ADR 0005: kind matrix is 1.34/1.37 (kind v0.33.0 ships no 1.33 image); `[profile.dist]` lives in `.cargo/config.toml`.
- ADR 0006: providers dispatch through an enum instead of `dyn Provider` + async-trait.
- ADR 0007: the AWS SDK runs on rustls + ring via `aws-smithy-http-client`.
- ADR 0008: `find_problems` covers Services and PVCs from v0.2, with the §9.2 `svc.*`/`pvc.*` rules.
- ADR 0009: logs are scrubbed of the exact values of the Secrets their pod references.
